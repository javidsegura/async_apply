# Mode: find-contact-queries — Propose search phrasings

Propose 3 to 5 search-engine queries most likely to surface a real LinkedIn
profile for the best outreach target: the hiring manager for this team, the
recruiter assigned to this kind of role, or a peer doing similar work.

You are not searching yourself and will not see any results. Another process
runs every query you write and only ever offers the candidate profiles those
searches actually returned — so there is nothing to gain from guessing a
name; write phrasings that are likely to find a real page, not an answer.

Rules, learned from what this search backend actually does:

- It is not Google: `site:`, quotes, and other operators return nothing.
  Write plain keywords.
- Adding the role's location to a query is a coin flip: it sometimes helps
  and sometimes drops a query from several hits to zero, unpredictably even
  on identical repeats. **Only 1 or 2 of your queries should include the
  location; the rest must rely on company and role alone**, so a bad location
  guess never costs every attempt.
- End every query with the word `linkedin`.
- Vary the angle across your queries rather than lightly rewording the same
  one: try the role title, a likely job title one level up (e.g. "engineering
  manager"), "recruiter" or "talent acquisition", and a peer-level phrasing.
